# Network Troubleshooting Methodology

This project documents my progress through a series of network troubleshooting labs created by [WittyNetworks.net](https://wittynetworks.net/) using Cisco Packet Tracer.

Each lab begins with the root cause unknown. The goal is to improve my troubleshooting skills through repeated hands-on practice and develop a more consistent troubleshooting process over time.

For each scenario, I document:

- Reported symptoms
- Troubleshooting process
- Commands and tests used
- Mistakes and wrong turns
- Escalation point, if needed
- Root cause and resolution when solved independently
- Lessons learned
- YouTube walkthrough

## Result Classifications

Each lab will have one of two results:

- Resolved Independently - I identified the root cause and resolved the issue without reviewing the Witty Networks answer.
- Escalated - I reached a point where I could not identify or resolve the issue independently and reviewed the Witty Networks answer.

## Project Goal

I do not currently have a fully developed troubleshooting methodology.

I am using these labs to improve how I investigate network problems, narrow down possible causes, and make troubleshooting decisions based on the results of each test.
